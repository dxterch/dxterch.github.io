# Dexter Chua — Personal Website

[#dexter-chua--personal-website](#dexter-chua--personal-website)

My personal homepage for IS216 Web Application Development II, built with plain HTML, CSS, and JavaScript (no frameworks or libraries).

🔗 **Live site:** <https://dxterch.github.io/>

## Features

[#features](#features)

- Fixed navbar with smooth anchor navigation to each section
- About Me card with a profile photo (hover-flip effect) and short bio
- Favorite travel destination card with an embedded, autoplaying YouTube video
- Interactive Singapore map with positioned Home/School markers, hover tooltips, and a legend
- Weekly learning log table tracking topics, assessments, and key dates across the course
- Skills & Tools, Projects, and Contact sections styled as pill-badge lists
- "Back to Top" floating button
- Fully responsive card-based layout using Flexbox (no CSS frameworks)

## Project structure

[#project-structure](#project-structure)

```
index.html      → personal homepage (About, Travel, Map, Learning Log, Skills, Projects, Contact)
styles.css      → all styling for index.html
Images/         → profile photo, Singapore map graphic, and other site images
fanpage.html    → Fernando Alonso fanpage (see below)
Challenge1/     → Week 2 - Margin, Padding, Border
Challenge2/     → Week 2 - Element, Class, ID Selectors
Challenge3/     → Week 2 - Positioning
```

## Built with

[#built-with](#built-with)

- HTML5
- CSS3 (Flexbox, custom properties)
- Vanilla JavaScript (no frameworks or libraries)

## Week 2 — CSS Land Challenges

[#week-2--css-land-challenges](#week-2--css-land-challenges)

A set of standalone CSS practice exercises themed around a fictional amusement park, "CSS Land." Each challenge ships with a fixed `home.html` (not to be modified) and a `styles.css` skeleton to complete.

🔗 **Live pages:**

- Challenge 1: <https://dxterch.github.io/Challenge1/home.html>
- Challenge 2: <https://dxterch.github.io/Challenge2/home.html>
- Challenge 3: <https://dxterch.github.io/Challenge3/home.html>

| Challenge       | Topic                          | Description                                                                                                                           |
| --------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Challenge 1** | Margin, Padding, Border        | Styles a park welcome page — spacing, borders, fonts, colors, and button hover states.                                                |
| **Challenge 2** | Element, Class, & ID Selectors | Builds an attractions gallery of ride cards using flexbox, hover animations, and image styling.                                       |
| **Challenge 3** | Positioning                    | Builds an interactive park map with absolutely-positioned markers, hover tooltips, a pinned legend, and a fixed "Back to Top" button. |

Each challenge folder contains:

```
home.html      → fixed markup (do not modify)
styles.css     → CSS skeleton to complete
README.txt     → link to full challenge instructions
```
